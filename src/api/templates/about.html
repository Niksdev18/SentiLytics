About the project and the team behind Sentilytics
About Sentilytics

Built to Make
Markets Readable

Sentilytics is a final-year BTech project that combines transformer-based NLP, ensemble machine learning, and real-time financial data to turn raw news into actionable market intelligence.

🧠
FinBERT Transformer
Fine-tuned on financial tone data with 90.03% test accuracy. Outperforms every classical ML baseline by ~4%.
📊
7 Models Benchmarked
Logistic Regression, SVM, XGBoost, Random Forest, Naive Bayes, Stacking & Voting Ensembles — all compared.
📡
Real-Time Pipeline
NewsAPI + yFinance integration fetches fresh data every 2 hours. Sentiment is always current with the market.
💡
Smart Trading Signals
Combines sentiment confidence + price movement direction to produce BUY / SELL / HOLD recommendations.
🔌
REST API
POST any financial text to /api/predict and get sentiment + confidence back in JSON.
🚀
Production Deployed
Deployed on Render with gunicorn. FinBERT model hosted on HuggingFace Hub. Accessible from anywhere.
